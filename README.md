# HTTP Server in TypeScript

A simple HTTP server built with TypeScript as part of the **Boot.dev** backend curriculum.

This project focuses on the fundamentals of building web servers without relying on full-featured frameworks. It covers routing, middleware, authentication, request handling, and building REST-style APIs.

## Features

- HTTP server built with TypeScript
- Custom routing
- Middleware support
- Authentication
- REST API endpoints
- Request and response handling
- Error handling
- JSON parsing
- Static file serving (if implemented)

## Tech Stack

- TypeScript
- Node.js
- HTTP module

## Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/http-server-typescript.git
cd http-server-typescript
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build the project

```bash
npm run build
```

### Start the production server

```bash
npm start
```
